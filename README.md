# Alerta-De-EnchentesESP32


## 📌 Sobre o projeto

projeto de IoT desenvolvido para monitorar o nível da água e a intensidade da chuva, identificando possíveis situações de risco de enchentes.

O sistema utiliza sensores conectados a um ESP32 do Site Wokwi.com para coletar informações e enviar os dados via MQTT para a plataforma ThingsBoard, permitindo o acompanhamento por meio de um dashboard.

## Dispositivos utilizados

- 1 ESP32 Devkit V1
- 1 HC-SR04 (sensor ultrassônico)
- 1 Potenciômetro (simulação da intensidade da chuva)
- 1 Display OLED
- 3 LEDs indicadores (Verde, Amarelo e Vermelho)
- 3 Resistores de 220 Ω (ohms)
- 1 Buzzer
- 1 Protoboard
- Fios Jumpers (Utilizados para interligar o ESP32, a Protoboard, sensores, Display OLED, LEDS e o Buzzer
  Permitindo a distribuição de alimentação, Distribuição do GND e sinais de comunicação)
