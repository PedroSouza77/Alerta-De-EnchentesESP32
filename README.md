# Alerta-De-EnchentesESP32


## 📌 Sobre o projeto

projeto de IoT desenvolvido para monitorar o nível da água e a intensidade da chuva, identificando possíveis situações de risco de enchentes.

O sistema utiliza sensores conectados a um ESP32 do Site Wokwi.com para coletar informações e enviar os dados via MQTT para a plataforma ThingsBoard, permitindo o acompanhamento por meio de um dashboard.

## Dispositivos utilizados

- ESP32
- HC-SR04 (sensor ultrassônico)
- Potenciômetro (simulação da intensidade da chuva)
- Display OLED
- LEDs indicadores
- Buzzer
- Conexão MQTT
